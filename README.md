# Staff Module

Welcome to the Staff Module of our Clothing Brand Management System.

This portal is made for staff members to manage daily order activities easily. It helps the staff team handle clothing orders, keep delivery information up to date, write helpful processing notes, and review all completed orders.

## What Staff Can Do

1. Staff Registration and Login: New staff can create an account and log in securely.
2. Staff Dashboard: View quick order numbers and fast shortcut links.
3. Order Management: Check customer orders and update the status between Pending, Processing, and Delivered.
4. Order Notes: Add helpful packaging instructions or special requests for any order.
5. Delivery Management: Set delivery addresses, choose courier partners, and track shipment progress.
6. Completed Orders: Search and review all finished orders in one clean table.
7. Staff Profile: View and edit personal information and change account passwords.

## Technology Used

This project is built using basic web technologies:

* HTML for clean page structure
* CSS for soft pastel styling and responsive layout
* JavaScript for simple form checks and quick page updates

All files for this module are organized neatly inside the staff mid codes directory.
